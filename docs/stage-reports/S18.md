## 人工复核步骤

1. 小程序创建住宿订单，点击支付，确认 `/api/orders/{id}/pay` 返回 `paymentRequest`，完成支付后调用 `/api/orders/{id}/pay/confirm`，确认订单详情显示 `paymentStatus = PAID`、`paymentRecordStatus = SUCCESS`、`transactionId` 非空。
2. 在小程序提交退款申请，管理端审批通过后确认订单先展示 `paymentStatus = REFUND_PENDING`，并在详情页看到最新退款流水编号与状态 `PROCESSING`。
3. 触发微信退款成功回调后刷新小程序与管理端，确认订单变为 `paymentStatus = REFUNDED`、`latestRefundStatus = SUCCESS`、`refundedAt` 有值；若回调返回 `ABNORMAL/CLOSED`，确认管理端可点击重试退款。
