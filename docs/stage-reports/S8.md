# S8 Stage Report

## 需求确认

- 本 Stage 目标：实现管理端订单列表/详情、后台改期与退款处理接口，以及经营概览摘要接口，支撑最小运营闭环。
- 本 Stage 边界（不做）：不创建 Web 管理后台工程（S9），不引入正式后台账号/RBAC 体系，不补充分页导出或复杂报表维度。

  - 订单列表支持 `status`、`keyword`、`checkInStartDate`、`checkInEndDate` 组合筛选，默认按创建时间倒序返回。

  - 经营概览按当前订单快照统计：总订单数、待入住单数、退款单数、成交额（`CONFIRMED` / `RESCHEDULED` / `COMPLETED` 汇总）。

## 人工复核步骤

1. 启动后端后，使用 `Authorization: Bearer <admin-token>` 调用 `GET /api/admin/orders`，分别传入 `status`、`keyword`、`checkInStartDate/checkInEndDate`，确认筛选结果与排序正确。
2. 调用 `GET /api/admin/orders/{id}` 查看订单详情，确认返回包含 `userId`、住客信息、金额、售后时间字段。
3. 对已支付订单调用 `POST /api/admin/orders/{id}/reschedule` 与 `POST /api/admin/orders/{id}/refund`，确认状态更新、`afterSaleReason` 回写、库存同步释放或重锁。
4. 调用 `GET /api/admin/reports/summary`，确认 `orderCount`、`pendingCheckInCount`、`refundedOrderCount`、`revenueAmount` 与当前订单状态快照一致。
