## 人工复核步骤

1. 启动后端与 `sunflower-admin-web`，使用有效管理端 token 登录后台并进入“订单售后”页面。
2. 在筛选区输入订单号/入住人关键词，切换状态为“待入住”并设置入住开始/结束日期，确认列表结果按条件收敛。
3. 点击任一 `CONFIRMED` 或 `RESCHEDULED` 订单的“查看详情”，确认抽屉内展示经营状态、入住人信息、时间线、备注与售后记录。
4. 在抽屉中执行“改期处理”，选择新的入住/退房日期并填写原因，提交后确认状态更新为“已改期”，日期与售后原因同步刷新。
5. 对另一笔可售后订单执行“退款处理”，填写退款原因并提交，确认状态更新为“已退款”；可选地制造非法状态订单，确认页面显示后端返回的失败文案。
