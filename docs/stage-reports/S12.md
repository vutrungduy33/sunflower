## 人工复核步骤

1. 启动后端并确认 `curl http://localhost:8080/api/health` 可用；在 `sunflower-admin-web/` 执行 `export PATH="$HOME/.local/node-v20.20.1-darwin-arm64/bin:$PATH"` 后运行 `npm run dev`。
2. 访问 `http://localhost:5173/login`，使用管理端 token 登录后进入 `http://localhost:5173/pricing`，确认页面展示房型选择、窗口范围、上一段/下一段/回到今天按钮，以及卡片式价格日历。
3. 在日历中依次点击一个开始日期和一个结束日期，确认顶部提示变为已选区间，选中卡片出现明显高亮，批量发布区域同步显示天数、均价和最低库存摘要。
4. 点击“单日调价”或“周末连住”等快捷区间，确认选区即时切换；再输入批量价格后点击“更新价格”，确认出现成功提示，并在“变更反馈”卡片中看到对应日期和价格。
5. 继续输入批量总库存后点击“更新库存”，确认出现成功提示，并在“变更反馈”卡片中看到总库存、可售库存和锁定库存回写结果。
6. 点击“上一段 / 下一段 / 回到今天 / 刷新日历”，确认窗口范围文案和日历卡片随之刷新，且旧选区被清空，避免误操作。
