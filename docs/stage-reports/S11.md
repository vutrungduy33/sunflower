## 人工复核步骤

1. 启动后端并确认 `curl http://localhost:8080/api/health` 可用；在 `sunflower-admin-web/` 执行 `export PATH="$HOME/.local/node-v20.20.1-darwin-arm64/bin:$PATH"` 后运行 `npm run dev`。
2. 访问 `http://localhost:5173/login`，使用管理端 token 登录后进入 `http://localhost:5173/rooms`，确认页面展示房型统计、列表和“新建房型”按钮。
3. 点击“新建房型”，填写完整表单后保存，确认出现成功反馈，列表新增对应房型。
4. 点击任意房型“编辑”，修改名称或基础价格后保存，确认列表内容刷新为最新值。
5. 点击房型“下架/上架”按钮，确认状态标签变化；下架后通过后台列表仍能看到该房型，但前台 `/api/rooms` 不再返回该房型。
6. 打开 `docs/Code-Conventions.md`、`README.md` 和 `docs/README.md`，确认新增代码规范已可从文档入口找到，且规则覆盖通用、后端、Web、小程序四类约束。
