  - 新增 Vitest 路由级测试，覆盖未登录跳转、登录成功回跳和登录失败提示。

## 人工复核步骤

1. 执行 `export PATH="$HOME/.local/node-v20.20.1-darwin-arm64/bin:$PATH"`，进入 `sunflower-admin-web/` 运行 `npm run dev`。
2. 启动后端并确认 `curl http://localhost:8080/api/health` 可用，然后访问 `http://localhost:5173/login`，页面应显示“管理端登录”。
3. 输入错误 token 并提交，确认页面提示“管理端登录态无效”或“请先登录管理端”等后端返回错误，且不会进入业务页。
4. 使用后端 `app.admin.auth.token` 对应 token 登录；本地默认开发值可参考 `sunflower-backend/src/main/resources/application.yml` 的 `ADMIN_AUTH_TOKEN` 默认值。登录后应进入目标业务页，并可看到侧边菜单、顶栏和“退出登录”按钮。
5. 手动访问 `http://localhost:5173/rooms`、`/pricing`、`/orders`，确认未登录时都会跳回 `/login`；登录后可进入各自占位页。
6. 点击“退出登录”，确认回到 `/login`，再次直接访问业务路由时继续被拦截。
