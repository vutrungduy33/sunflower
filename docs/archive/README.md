# Historical Archive

This directory contains historical planning, stage reports, old release gate
documents, and older MVP progress logs.

These files are preserved for traceability only. They are not active process
requirements and should not be used as the source of truth for current
development workflow, branch naming, commit messages, PR gates, or stage guard
checks.

Current source-of-truth documents:

- `../../AGENTS.md`: current agent/development notes
- `../README.md`: current documentation index
- `../Architecture.md`: current system architecture
- `../CI-CD.md`: current GitHub Actions deployment pipeline
- `../S19-Prod-Deployment-Config.md`: current production deployment config

Notable archive subdirectories:

- `planning/`: early product, UX, analytics, code-convention, and definition of
  done documents that are useful as background but are no longer default
  loading context.
- `mvp-progress/`: older round-by-round MVP progress logs. Keep only the latest
  operational rounds in `../MVP-Progress.md`.
